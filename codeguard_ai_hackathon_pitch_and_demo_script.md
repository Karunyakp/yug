# CodeGuard AI: Hackathon Pitch & Recording Script

## 🎯 Pitch Summary

### Opening Hook
> "What if code-similarity tools helped educators ask better questions instead of making accusations? **CodeGuard AI** is a human-led academic code review workspace. It brings code comparison, visible evidence, review workflows, exports, and optional AI assistance together—while making clear that a similarity score is not proof."

### Differentiator & Core Philosophy
* **Key Positioning:** We don't claim "AI catches cheating."
* **Value Proposition:** Evidence-first review with transparent limitations and human accountability.

### Closing Statement
> "CodeGuard AI doesn’t decide whether a student cheated. It helps educators examine the evidence, ask informed questions, and make a fair decision themselves."
