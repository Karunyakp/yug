HACKATHON DEMO PLAN

CodeGuard AI

Pitch Summary, 2-Minute Script & Pre-Recording Safety Guide

🎯 Pitch Summary

Opening Hook:

“What if code-similarity tools helped educators ask better questions instead of making accusations? CodeGuard AI is a human-led academic code review workspace. It brings code comparison, visible evidence, review workflows, exports, and optional AI assistance together—while making clear that a similarity score is not proof.”

Judge-Facing Differentiator:

Your differentiator is not “AI catches cheating.” It is “evidence-first review with transparent limitations and human accountability.”

Closing Statement:

“CodeGuard AI doesn’t decide whether a student cheated. It helps educators examine the evidence, ask informed questions, and make a fair decision themselves.”

⏱️ 2-Minute Video Flow & Script

Time Show (Visual / Screen Action) Say (Audio / Presentation Script)
0:00–0:15 Start on the Home Page “Code review integrity is difficult: similar code can be a useful signal, but it isn’t proof of misconduct. CodeGuard AI is a review workspace designed to help educators inspect evidence and keep decisions human-led.”
0:15–0:30 Open All Features view “The platform brings code comparison, review workflows, reporting, communication, and optional AI assistance into one experience.”
0:30–0:45 Sign in, then show the Dashboard “This frontend demo includes a dashboard and connected screens for submissions, assignments, reports, and review staff. Some of the dashboard content is illustrative sample data.”
0:45–1:15 Open Code Analysis / Compare. Run analysis on the prefilled example. Show the comparison and evidence. “Here, an instructor can compare two code samples and inspect the local similarity indicators. When Gemini is configured and available, the app can also provide AI-generated observations. Those observations are advisory—not a verdict.”
1:15–1:30 Briefly show the AI error/fallback state if available, or just explain it “If the AI service isn’t available, the app labels its local heuristic findings clearly instead of pretending they came from AI. That makes the limitation visible to the reviewer.”
1:30–1:45 Open Reports and point to CSV/PDF export options “Review data can be exported from the browser as CSV, and reports can be printed to PDF. Account exports omit password hashes.”
1:45–2:00 Show the Assistant button, then finish on the home page “CodeGuard AI is a frontend-first prototype: accounts are browser-local, and connected AI or email features depend on configuration. Our goal is to make review more transparent—not to automate judgment.”

  • Use only sample code already present on the Compare page. Do not display real student submissions or personal data.
  • Avoid presenting the dashboard's sample counts as real institutional activity.
  • Do not claim university adoption, FERPA compliance, guaranteed accuracy, or automated AST capabilities unless you can independently demonstrate and substantiate them.
  • Hide browser tabs, system notifications, passwords, API keys, and developer tools in the recording.
  • Keep screen transitions quick; allocate maximum time to showing the comparison evidence and explaining why the final decision remains human-led.
